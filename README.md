## Overview

Max Stack Plus raises item stack limits across Terraria's entire item catalog with configurable multipliers, massively reducing inventory shuffling during large builds and boss prep sessions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Max Stack Plus** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Stack Multiplier** | Apply a global multiplier to all item types simultaneously |
| **Per-Category Config** | Set separate limits for blocks, ores, potions, and ammo |
| **Mod Item Support** | Auto-detects and applies limits to items added by other mods |
| **No Dupe Exploit** | Stack increases affect storage only; drop splits remain vanilla |
